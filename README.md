# Employee Management System Frontend

## Overview
A responsive Employee Management System developed using HTML, CSS, and JavaScript.

## Features
- Add Employee
- Edit Employee
- Delete Employee
- Search Employees
- Filter by Department
- Filter by Employee Type
- Dashboard Analytics
- Form Validation
- Department-Based Designations
- Local Storage Support

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage

## Dashboard Metrics
- Total Employees
- Total Departments
- Permanent Employees
- Contract Employees
- Trainees / Interns
- Average Salary
